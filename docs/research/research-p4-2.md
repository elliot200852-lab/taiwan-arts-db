## 紅隊關卡（動筆前先寫，redteam-gate.md）

1. **李泰祥帕金森氏症確診年**：維基寫 1988、國立傳統藝術中心臺灣音樂群像資料庫寫 1998，差十年。→ **處置：三頁全文不標年，只寫「晚年為帕金森氏症所苦」**，年份留給日後有第三來源再補。
2. **席德進出生地「四川南部」**：這是縣名（四川省南部縣），極易被讀成「四川的南部地區」，寫錯就是地理錯誤。→ **處置：一律寫「四川南部縣」**，並在課堂用法不做四川地理延伸。
3. **顏水龍創辦南投工藝機構的年份**：維基寫 1956 年「南投縣手工藝研習班」，國立臺灣工藝研究發展中心自己的〈緣起沿革〉寫 1954 年「南投縣工藝研究班」。→ **處置：採該機構官方版 1954 年、官方機構名「南投縣工藝研究班」**，維基那條不採。
4. （附帶）**李泰祥 1961／1964 兩個時間軸打架**：國家文藝獎頁寫 1961 畢業、1964 進北市交；維基寫 1964 畢業後隨即受聘；音樂群像寫「畢業後於臺東教書 5 年」；臺灣音樂館寫 1966–1968 在臺東教學。→ **處置：只寫兩源一致的「1964 年起任臺北市立交響樂團小提琴首席」，臺東教書不繫年、也不與畢業做因果串接。**
5. （附帶）**李泰祥金馬獎**：1981 年《名劍風流》最佳原作音樂有維基＋音樂群像＋臺灣音樂館三源；1979 年《歡顏》最佳電影插曲只有維基 infobox 單源。→ **處置：只寫 1981 那座，1979 那座不寫。**

## 一、李泰祥 li-tai-hsiang（立頁）

**tags [音樂]｜field 音樂 · 作曲｜years 1941–2014｜geo 臺東縣 taitung.html**

### 逐事實來源

- 1941-02-20 生於臺東馬蘭、2014-01-02 逝於新店（享壽 73）→ **維基「李泰祥」**＋**國家文藝獎第 12 屆得主頁**（「1941 年生於台灣台東縣」「2014 年 1 月 2 日辭世，享壽 73 歲」）＋**臺灣音樂群像資料庫**（「出生於臺東馬蘭」）三源一致。
- **族裔寫法**：臺灣音樂館 openmuseum〈人物 · 李泰祥〉明寫父為「阿美族青年李光雄」、母為「漢人妻子李蓮戀」。→ 頁面寫「父親是馬蘭部落的阿美族人、母親是漢人」，**不寫成「阿美族音樂家」單一標籤**（維基用該標籤，但館所來源更精確）。
- 1956 年考進國立臺灣藝術專科學校美術印刷科、後轉音樂科主修小提琴 → **國家文藝獎頁**（「1956 年考入國立台灣藝專美術印刷科，而後轉入音樂科，主修小提琴」）＋**音樂群像**（「1956 年進入國立臺灣藝術專科學校就讀美術印刷科，後轉入音樂科主修小提琴」）＋維基，三源一致。
- 許常惠為其精神導師 → **臺灣音樂館 openmuseum**（「許常惠老師成為他的精神導師，改變了他的一生」）＋**音樂群像**（「其後深受許常惠影響」）。
- 1964 年起任臺北市立交響樂團小提琴首席 → **維基**＋**國家文藝獎頁**（見紅隊 4 的處置）。
- 曾回臺東教書 → **音樂群像**（「畢業後於臺東教書 5 年」）；**不繫年**。
- 1971 年七一樂展、臺灣前衛音樂起點 → **國家文藝獎頁**（「七一樂展」「台灣前衛音樂之誕生」）＋維基（策劃者名單）。
- 1970 年代中期決心改革通俗音樂、《橄欖樹》《一條日光大道》《你是我所有的回憶》等 → **音樂群像**。《橄欖樹》1971 年創作、1979 年齊豫首唱 → **國家文藝獎頁**。
- 嚴肅音樂《太虛吟》《氣、斷、流》《生民》《幻境三章》、清唱劇《大神祭》 → **國家文藝獎頁**＋**音樂群像**＋維基三源交集。
- 1981 年《名劍風流》金馬獎最佳原作音樂 → **音樂群像**＋**臺灣音樂館**＋維基（見紅隊 5）。
- 1997 年吳三連藝術獎、金曲獎特別貢獻獎 → **國家文藝獎頁**＋**臺灣音樂館**＋維基。
- 2008 年第 12 屆國家文藝獎 → **國家文藝獎官網得主頁本身**＋**臺灣音樂館**。
- 2013-04-19 第 32 屆行政院文化獎、林懷民擔任引言人、與侯孝賢同屆、李泰祥在醫護人員陪同下出席 → **國家文化記憶庫〈第 32 屆行政院文化獎引言人林懷民〉**（頒獎日期、引言人、雲門那段話原文）＋維基。
- 1972 年林懷民自美返臺，與李泰祥、許博允、三毛聊怎麼把現代樂與舞蹈放在一起，雲門舞集隔年誕生 → **國家文化記憶庫**同一筆（引林懷民引言原話）。**這條當「一個小故事」。**
- 晚年為帕金森氏症所苦、病中仍持續創作、多次參與音樂會 → 維基＋音樂群像（「飽受帕金森氏症之苦，但卻展現毅力，仍有作品問世」）＋國家文藝獎頁（「吃藥過後的兩至三小時，是李泰祥最可以創作的時候」、《情奔》「在電腦前一個按鍵一個按鍵慢慢『按』出來的」）。

### 歌詞紅線處理

- 全頁**除歌名外零歌詞**。《橄欖樹》只寫「三毛寫的詞、李泰祥譜曲、齊豫唱」與它在民歌運動中的位置，不轉述、不改寫、不節引任何一句歌詞。
- 林懷民那句「在那個哪裡都不能去的年代，李泰祥的《橄欖樹》呈現一個遙遠的夢想」是**評論者對歌的評語、不是歌詞**，屬可引；但為避免爭議，頁面採轉述而非逐字引號。
- 歌曲線 `content/songs/era-folk.yaml` 已登記他的 4 首（橄欖樹／歡顏／答案／走在雨中，皆帶 YouTube 連結）。人物頁作品段**只寫歌名並用《》包住**，由 build 的 WorksLinker 自動掛鏈到登記簿既有連結，**不另貼 URL**。

### 棄用素材

- 維基「十五歲便拿下全省小提琴大賽冠軍」：單源，未搜得第二來源 → **不寫**。
- 維基「因過去賣斷版權，分不到版稅，晚年經濟困頓」：單源、且屬個人財務，敏感 → **不寫**。
- 1974 年任何一個樂團的指揮職：維基寫北市交、國家文藝獎頁寫省交＋臺大管弦樂團，互斥 → **整項不寫**。
- 2000 年腦部脈衝產生器植入手術：來源夠（國家文藝獎頁），但屬醫療細節、對備課無用 → 不寫。

## 二、席德進 shiy-de-jinn（立頁）

**tags [美術]｜field 美術 · 油畫與水彩｜years 1923–1981｜geo 臺中市 taichung.html**

### 地理錨點的取捨（規格說「由來源決定」）

候選：鹿港／淡水（他長年畫古厝的現場，但無單一權威來源把他釘在某一鎮）、嘉義（1948 來臺首站任教嘉義中學，只待了兩三年）、臺中（**1981-08-12 葬於臺中市大肚山大度山花園公墓**；**1992 年遺作捐予臺灣省立美術館＝今臺中的國立臺灣美術館**，國美館至今是他作品的最大典藏地與歷屆紀念展主場）。
→ **採臺中市**：兩件事都有來源、都指同一座城，而且對備課老師最實用（要看真跡就去國美館）。

### 逐事實來源

- 1923-06-28 生於四川南部縣、1981-08-03 逝世（58 歲）、胰臟癌 → **維基「席德進」**（生卒、1980-08-24 因胰臟癌入榮總開刀、1981-08-03 凌晨病逝）。
- 成都技藝專科學校受留法畫家龐薰琹啟發、轉入沙坪壩國立藝術專科學校受教於林風眠、與趙無極朱德群李仲生往來 → **維基**；1943 入杭州國立藝專、1948 畢業 → **國美館展覽〈履痕深烙：席德進早期的生命和藝術軌跡, 1943-1966〉展頁**。
- 1948 年夏末隻身自杭州轉上海來臺、初在嘉義中學任教、足跡遍布嘉義近郊與南臺灣城鄉 → **國美館展頁**＋維基（「1948 年隨國民政府來到台灣，在嘉義高中短暫任教」）。
- 1951／1952 北上臺北成為專業畫家、靠插畫廣告維生、走遍臺北近郊寫生 → 維基（1951）＋**國美館展頁**（1952）。**頁面寫「一九五○年代初北上臺北」框住兩說。**
- 1962 年受美國國務院之邀赴美、1963 移居巴黎、1965 在巴黎研究中國藝術並辦個展、1966 返臺 → 維基年譜＋**國美館展頁**（「1962 年受美國國務院之邀赴美體驗現代藝術的機會」「在巴黎居留三年」）。
- 返臺後轉向臺灣鄉土的老屋建築與平凡人物 → **國美館展頁**原文：「中華文化的美感精神，和臺灣鄉土題材裡的老屋建築和平凡人物，佔據了他後半生的創作」。
- 1970 年起試把臺灣山水與現實景物轉為水墨筆意、1973 年起於《雄獅美術》陸續發表臺灣美術資料整理 → 維基年譜。
- 晚期大量水彩寫生臺灣古厝與風景、是最早以水彩記錄臺灣民間建築之美的畫家、作品現藏國立臺灣美術館 → **taiwanmd〈台灣水彩畫的百年流變〉**（帶腳註的主題文）。
- 1972 年為彰化孔廟保存案撰文呼籲；1978 年呼籲保存林安泰古厝原貌 → 維基年譜。
- **林安泰古厝那條的第二來源**：**維基「林安泰古厝」**獨立記載——「席德進常帶外國朋友來參觀，也常帶他的學生前往寫生」；1977-03-08 新建工程處邀專家討論拆遷，「席德進、李乾朗皆反對拆遷」；後來馬以工把漢寶德、孫鐵剛、李乾朗、王鎮華、席德進、黃鴻銘等人的討論編成《再見林安泰》；此次保護運動促成《文化資產保存法》制定。古厝 1978-06-26 起解體、1984 起於濱江公園重組、1987-06-05 開放。**（他 1981 年過世時古厝還沒重組完成——這個時間差是頁面「一個小故事」的收尾，兩條年份都出自同一篇獨立條目。）**
- 1981-08-12 葬於臺中市大肚山大度山花園公墓 → 維基年譜。
- 1992 年遺作捐予臺灣省立美術館（今國立臺灣美術館） → 國美館歷次紀念展新聞（「席德進的遺世畫作於 1992 年捐予臺灣省立美術館」）；國美館典藏查詢系統有其作品頁（活性已測，見末段）。

## 三、顏水龍 yen-shui-long（立頁）

**tags [美術, 工藝]｜field 美術 · 油畫與工藝設計｜years 1903–1997｜geo 臺南市 tainan.html**

### 逐事實來源

- 1903-06-05 生於臺南下營紅毛厝（日治茅港尾西堡）、1910 年父母先後去世、1997-09-24 病逝臺中榮總（94 歲）、歸葬故鄉紅毛厝 → **維基「顏水龍」**；「出生於臺南下營的顏水龍，年幼父母早逝，與姊姊及祖母生活」→ **臺南市美術館〈臺南囡仔顏水龍〉展頁**（第二來源）。
- 1915 下營公學校畢業→臺南廳教員養成所→1918 回母校任教→1920 赴東京私立正則中學→1922 考進東京美術學校西畫科、受教藤島武二與岡田三郎助 → 維基。
- 1929 年因霧峰林獻堂資助留法、1930 抵法、於大茅舍藝術學院學習、1931 以《少女》《蒙特梭利公園》入選法國秋季沙龍、1932 返日 → 維基。
- 1934／1937 與楊三郎、廖繼春等創立臺陽美術協會與臺陽展 → 維基（人名與年份與 `content/fields/field-art.md` 既有臺陽敘述不衝突，已比對）。
- 1933 年起在大阪做牙粉廣告設計、1940 在臺南州北門地區創「南亞工藝社」教在地人用鹹草編製生活用品並外銷 → 維基。
- 1944 起任教臺南高等工業學校（今成功大學）、後至臺南家專與實踐家專 → 維基。
- **1954 年在草屯創辦「南投縣工藝研究班」、設竹工木工車床雕刻籐工陶瓷編織七科、為今日國立臺灣工藝研究發展中心前身** → **工藝中心官方〈緣起沿革〉**（原文：「起源於 1954 年的『南投縣工藝研究班』……由臺灣工藝先驅的顏水龍（1903-1997）在草屯成立」）＋**工藝中心「尋找顏水龍」特展新聞稿**。**採官方年份 1954，不採維基的 1956（見紅隊 3）。**
- 「臺灣工藝之父」這個稱號 → **工藝中心特展新聞稿**（「歡迎想更了解臺灣工藝之父顏水龍的民眾」）＋**臺南市美術館展頁**（「獲得『臺灣工藝之父』的榮譽」）兩個公立館所都用，可放心寫。
- 「工藝生活化，生活工藝化」「生活就是藝術」與「將美和生活結合的工藝品創作以至生產，乃是文化和經濟的一道源泉」 → **工藝中心特展新聞稿**。頁面只用最後一句的**轉述**，不逐字引號（避免二手轉引風險）。

### 年份與說法的處理

- **太陽堂餅店創立年**：維基寫 1954 林紹崧夫婦創立；taiwanmd〈太陽餅〉寫「1964 年……太陽堂餅店熱鬧開幕」。兩說互斥 → **頁面完全不寫餅店創立年**，只寫 1964 年的壁畫本身（兩源一致）。
- 維基把 1961 台中體育場《運動》記為「臺灣體育大學體育場」、作品表又寫「台中體育場」，自相不一致 → **整項不寫**，馬賽克只舉太陽堂與劍潭兩件（都有官方或帶腳註來源）。
- 《臺灣工藝》一書的初版年：維基未給、工藝中心 2016 有再版 → **只寫書名不寫年**。
